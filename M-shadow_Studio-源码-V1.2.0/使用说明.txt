M-shadow Studio  V1.2.0（2026/11）
Author：SeanZhou2933      反馈 Mail：zxq2933@qq.com

【系统要求】
Windows 10 / Windows 11，64 位（x64）。不支持 32 位系统与 Windows 7/8。

【怎么启动】
双击本文件夹里的「M-shadow Studio.exe」就能用，不需要安装 Node.js，也不需要联网安装依赖。
第一次启动 Windows 可能弹出「Windows 已保护你的电脑」：
  点「更多信息」→「仍要运行」即可（这是没做代码签名的正常提示）。
建议右键 exe → 发送到 → 桌面快捷方式，以后从桌面启动。
想要新图标：双击文件夹里的「创建桌面快捷方式.bat」，它会在桌面建一个带新 M 图标的快捷方式（bat 只建快捷方式，不动程序本身）。

【怎么用】
1) 左侧「导入文件」选 txt / pdf / word / mp3 / mp4，或点「粘贴文本」把一段英文直接贴进来，
   也可以点「粘贴视频链接」贴 B 站/YouTube 链接（整段分享文案一起粘进来也能自动识别出链接）。
2) 系统自动断句、翻译、生成配音。导入音频/视频或链接时，默认用素材原声，也可以在音源下拉里
   切回软件配音（原声按每句的起止时间精确截取，歌曲同样适用）。
3) 中间列表每句右边四个按钮，依次是：评分（还没评就显示「—」）、播放、跟读、回放我的录音。
   点句子文字只切换当前句、不播放；模糊模式下只有把鼠标放到文字上才变清晰。
4) 右侧「播放」是总控播放：从当前句念；正在念时点一下停止，再点从头开始。
   旁边的循环按钮四态切换：不循环 → 单句循环 → 全篇循环 → 无敌循环（读完本篇自动接素材列表下一篇）。
   单句 / 全篇的循环次数在「设置」里改，默认都是 5 次。
5) 右侧「评价与建议」显示本篇平均得分和评语（只统计这一篇已评分的句子），不再显示最高分，也没有自动下一句。
6) 「听写拼写」页按雅思高频词出题，题量在设置里（默认 10，上限 100–9999 可调）；
   进页面不自动播报，点播放键或按 1 才出声。
7) 「生词背诵」页可以导入 txt / pdf / word / csv 抽词建生词库（支持短语，也支持用逗号 / 斜杠 / 分号隔开的清单），先听词判断认不认识，认识再拼写；
   拼错次数在设置里调（默认 1 次）。播放键右边会遮住一个中文意思，点眼睛图标才看。
   生词本支持搜索、排序、分页（每页词数可调）、滚轮浏览、遮挡、多选删除。
   导入生词时先批量入库，再在后台补音标和中文意思；「从文件导入生词」按钮会显示绿色进度条，
   全部补完才算导入完成。点「导出单词本」会弹出导出设置，可选 CSV / TXT，
   导出项可选英文单词（必选）、音标、中文意思，还能直接填写或选择导出目录，点「导出」直接写文件。
   导出放到后台进行时，顶部「导出单词本」按钮会变成绿色进度条，期间可以正常用学习、听写等其他功能。
   生词库还支持「全部内容 / 全单词 / 全短语」下拉筛选；设置里每页词数选「全部」后不分页，一张表滚轮看到底。
   只有点「太简单了！」或主动进生词库删除，词才会真正移出。
   生词库表头可拖动调列宽；词性 / 中文意思太长时，鼠标移上去会弹出完整释义；点单词本身就能发音。

【左侧素材列表】
按住某个素材上下拖动，可以调整顺序；「无敌循环」就按这个顺序往下走。

【常用快捷键】
听写页 / 生词背诵页：1 重听、0 中文、2 提示、→ 下一个（Enter 也能检查/下一个）
生词背诵页额外：6「太简单了！」（从生词库移除）、9 重写一遍
这些键在「设置 → 快捷键」里按 学习跟读 / 听写拼写 / 生词背诵 三块分开改（数字键、单字母、方向键、F1–F12 都行）。
生词背诵的默认键：↑ 认识、↓ 不认识、1 重听、0 中文、2 提示、→ 下一个、6 太简单了、9 重写一遍。
听写页和生词背诵页各有一个「自动播报 开/关」按钮：开着每换一题自动读，关着点播放键或按 1 才读。

【标题栏】
没有 File / Edit / View / Window / Help 菜单栏；复制粘贴（Ctrl+C / Ctrl+V / Ctrl+X / Ctrl+A）照常可用。

【右上角三个按钮】
白天/夜晚模式 → 设置（舵盘）→ 帮助。默认白天，切换后会记住。

【语速】
全应用 5 档：0.5× / 0.75× / 1.0× / 1.25× / 1.5×，跟读和听写通用。

【设置里能改什么】
单句循环次数、全篇循环次数、听写题量上限、背单词拼错几次后显示答案、生词本每页词数、听写快捷键、环境自检。

【设置里的「环境自检」】
能看到 ffmpeg、本地识别模型、配音服务、yt-dlp、sharp 五项是否正常；全绿就说明跟读评分、链接导入都能用。
如果杀毒软件把 resources\bin\yt-dlp.exe 删了，链接导入会失败，重新放回该目录即可。

【语音识别模型】
软件内置 small.en（推荐，最准）和 tiny.en（最快）两个 Whisper 模型，装好即可离线识别。
如果你想用别的模型：把模型文件夹整个放进「程序目录\userdata\models\Xenova\你的模型文件夹」，
要求文件夹里有 config.json 和 onnx 模型文件；重启软件后，设置 → 语音识别 → 识别模型 的下拉里会出现「自定义」选项。
模型下载源只在选中的模型本地没有、需要联网下载时才会用到。

【数据放哪】
素材、录音、导出的 mp3、生词库都保存在程序目录下的 userdata 文件夹（帮助 → 关于里能看到具体路径），换电脑时拷走这个文件夹即可。

【卡住或报错】
配音偶发断流会自动重试一次；仍失败时换个音色再试。
跟读评分默认使用内置的 small.en（准确率最高）；如果电脑较慢，可在设置里换成 tiny.en，速度快一些。
